## 💸 Expense Manager

### Adding an Expense
1. Click the **"💸 Expenses"** tab
2. Fill in the form on the left:
   - **Title**: What is this expense for? (e.g., "Lunch", "Fuel")
   - **Amount**: How much did you spend?
   - **Date**: When did you spend it?
   - **Category**: Which category does it belong to?
3. Click **"Add"** button

### Editing an Expense
1. Click the **✏️ Edit** button on any expense
2. The form will populate with the expense data
3. Make your changes
4. Click **"Update"** button
5. Click **"Cancel"** to cancel editing

### Deleting an Expense
1. Click the **🗑️ Delete** button on any expense
2. Confirm the deletion in the popup

### Features
- ✅ Real-time validation
- ✅ Category dropdown from existing categories
- ✅ Total expense amount displayed
- ✅ Organized list with category badges and dates
- ✅ Scroll support for many expenses

## 📂 Category Manager

### Adding a Category
1. Click the **"📂 Categories"** tab
2. Type the category name in the input field
3. Click **"Add"** button
4. Category appears in the colorful card grid below

### Editing a Category
1. Click the **✏️ Edit** button on any category card
2. The input field will populate with the category name
3. Edit the name
4. Click **"Update"** button

### Deleting a Category
1. Click the **🗑️ Delete** button on any category card
2. Confirm the deletion in the popup
3. Note: This will affect any expenses/budgets using this category

### Features
- ✅ Colorful gradient card design
- ✅ Numbered categories
- ✅ Clean, organized grid layout
- ✅ Quick edit/delete buttons
- ✅ Responsive design

## 🐛 Troubleshooting

### "Failed to load data"
- Check that backend is running on port 8080
- Ensure you're logged in
- Refresh the page

### Can't edit a category
- Make sure the category exists
- Check browser console for errors
- Try refreshing the page

### Budget not appearing
- Verify the category exists
- Check the month/year selection
- Try adding the budget again

### Expense chart empty
- Add some expenses first
- Make sure expenses have categories assigned
- Refresh to see updated data
